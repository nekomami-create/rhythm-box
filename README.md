# リズムボックス (Rhythm Box)

16 ステップのステップシーケンサーで、ドラムを打ち込み、**和音（コード）とベースとリード**を重ねて曲に組み立てる Android アプリです。
音源ファイルは持たず、**すべての音をアプリ内で合成**しています（サンプル素材の同梱・ダウンロード不要）。

## 主な機能

- **16 ステップ x 8 音色**のドラム打ち込み（BD / SD / CH / OH / CP / RS / TM / CB）
- **コード（和音）**: 小節ごとにコードを指定。12 ルート x 8 種類（maj / m / 7 / m7 / M7 / sus4 / dim / aug）
  - コードとベースはドラムと同じ 16 ステップの行で「いつ鳴らすか」を打ち込む。**音の高さはその小節のコードから決まる**ので、コードを変えるだけで同じパターンが違う響きになります
- **リード（単音の旋律）**: 別タブのピアノロール（C4〜C6）で 1 ステップ 1 音を打ち込み
- **コードのおすすめ**: 曲に出てくるコードから調を推定し、**前後の小節に馴染むコード**を度数つきで提案
  （V → I、IV → V、vi → ii など、よくある進行の重みで並べ替え。両隣が分かっているときは
  「前から来やすく、次へ繋がりやすい」ものを上位にします）。曲構成のコードを丸ごと自動で埋めることもできます
- **リズムの自動生成**: ボタン 1 つでパターンを生成。8ビート / 4つ打ち / ブレイクビーツ / ヒップホップ / ラテン
  の 5 スタイル + おまかせ。気に入らなければ「戻す」で 1 つ前に戻せます
- **テンポ (40〜240 BPM)** とマスター音量、11 トラック（ドラム 8 + コード / ベース / リード）の音量・ミュート
- **パターン A〜H** の切り替え・クリア・コピー（パターンごとに試聴用のコードを持ちます）
- **3 つの再生の仕方**
  - パターン: 選んでいるパターン 1 小節をループ（打ち込みながら聴く用。常にループします）
  - **チェーン**: 中身のあるパターンを A→B→C… と 1 小節ずつ繋げて再生。曲構成を作らずに流して聴けます
  - 曲: 曲構成を通しで再生
  チェーンと曲のループは画面右上のループボタンで切り替え（既定はオン）。
  再生ボタンの下に「チェーン A→B→C をループ」のように今の状態が出ます
- **曲構成**: パターンを「A を 4 小節 → B を 2 小節…」と並べ、**小節ごとにコードを指定**して通し再生
- **自動保存 + 複数曲の管理**（新規作成・複製・名前変更・切り替え・削除）
- 再生中もその場で打ち込み・コードを変更できる（音は止まりません）
- 再生位置は実際に鳴っている音に合わせて表示（AudioTrack の再生位置を参照）
- トラック名や鍵盤をタップすると、その音だけを単発で試聴

## 使い方

1. 上部の **パターン** タブでグリッドをタップして打ち込み、▶ でループ再生。
   下 2 行（CHD / BAS）がコードとベースです。「コード」ボタンでこのパターンの和音を決められます。
2. **リード** タブのピアノロールで旋律を足す（同じマスをもう一度押すと消えます）。
3. 何も思いつかないときは「ランダム」でリズムを生成 → 気に入るまで押す →「戻す」で 1 つ前に復帰。
   複数のパターンができたら「チェーン A→B→C」で繋げて流せます（鳴っているパターンのボタンが光ります）。
4. パターン A〜H を切り替えて、いくつかのパターンを作る（「コピー」で複製してから変えると早いです）。
5. **曲構成** タブで「パターンを追加」→ 並び順と繰り返し小節数を指定 → 各行の下のコードボタンで小節ごとの和音を決める → ▶ で通し再生。
   コードを押すと「つぎに合うコード」が出るので、そこから選ぶだけでも進行になります。「コード進行おまかせ」で全小節を一気に埋めることも。
6. 編集内容は自動保存されます。曲の切り替えや新規作成は右上の ⋮ メニューから。

## 技術スタック

- Kotlin / Jetpack Compose (Material 3)
- 音声出力: `AudioTrack`（32bit float・モノラル・ストリーミング）
- 音源: 自前のシンセ（ドラムは作り置きの波形、コード / ベース / リードはその場で加算合成）
- 保存: kotlinx.serialization による JSON ファイル（`filesDir/songs.json`）

### モジュール構成

Android に依存する部分としない部分を分けています。`:core` は JVM 単体テストで検証できます。

```
core/   … 音源合成・シーケンサ・データモデル（純 Kotlin）
  Model.kt          パターン / コード / 曲 / ミキサー設定
  DrumSynth.kt      ドラム 8 音色のワンショット波形を合成
  ToneSynth.kt      コード / ベース / リードの音色（倍音構成と ADSR）
  ChordSuggester.kt 調の推定と「つぎに合うコード」、コード進行の自動生成
  PatternGenerator.kt リズムパターンの自動生成（スタイル別）
  PlaybackPlan.kt   「どの小節でどのパターンをどのコードで鳴らすか」（1 小節ループ / チェーン / 曲構成）
  PlaybackEngine.kt ステップ発音・発振器・ミックス・ソフトリミッタ
  StepTimeline.kt   再生位置の履歴（表示を音に合わせる）
  SongCodec.kt      JSON の読み書きと値の補正

app/    … Android アプリ（Compose UI / AudioTrack / ファイル保存）
  audio/AudioOutput.kt     AudioTrack への書き込みスレッド
  data/SongRepository.kt   自動保存つきの曲リポジトリ
  ui/                      画面（パターン / リード / 曲構成）・ViewModel・テーマ
```

## ビルド方法

Android Studio (Ladybug 以降推奨) でプロジェクトを開くか、コマンドラインから:

```bash
./gradlew :core:test           # 音源・シーケンサの単体テスト
./gradlew testDebugUnitTest    # アプリ側の単体テスト
./gradlew assembleDebug        # デバッグ APK をビルド
```

- **compileSdk / targetSdk**: 35
- **minSdk**: 26 (Android 8.0)

Android SDK のパスは `local.properties` に `sdk.dir=/path/to/Android/sdk` として設定するか、
`ANDROID_HOME` 環境変数で指定してください（このファイルは Git 管理外）。

GitHub Actions (`.github/workflows/android.yml`) でも単体テストと APK ビルドを行い、
`rhythmbox-latest` タグの **GitHub Release** に `RhythmBox.apk` を公開します
（Actions の成果物ストレージ枠を消費しないため）。最新版はいつも同じ URL から取得できます。

## アップデート（データを維持したまま更新）

固定のデバッグ署名鍵 (`app/debug.keystore`) を使うため、**新しい APK を上書きインストールするだけ**で更新でき、
保存した曲データはそのまま残ります（アンインストール不要）。

- ⚠️ `app/debug.keystore` はデバッグ用の鍵（パスワード `android`）です。Google Play で配布する場合は別途リリース用の署名鍵が必要です。

## 自動生成のしくみ

**コードのおすすめ** — まず曲に出てくるコードから調を推定します（24 通りの調について、音階に収まるコードの数で採点し、
最初と最後のコードが主和音になる調を優先）。そのうえで、機能和声のよくある進行を 7x7 の重みの表にしてあり、
今のコードの度数から次の度数を重み順に並べます。メジャーキーでは V7、マイナーキーでは和声的短音階の V（メジャー）も候補に足します。
進行の自動生成は同じ重みで確率的に選び、最後の 2 小節は必ず主和音へ帰る形（V/IV/ii/vii° → I）にしています。
曲の途中の小節を選び直すときは、前の小節から来る重みと次の小節へ向かう重みの相乗平均を取り、
片側だけに馴染む候補が上に来ないようにしています（C → ? → G なら F が最有力、C → ? → C なら G）。

**リズムの生成** — 完全な乱数だと音楽になりません。スタイルごとに「必ず置く位置」（キックの 1 拍目、スネアの 2・4 拍目など）を決め、
細かいところだけを確率で揺らします。ハイハットは確率で置くとランダムに穴が空いて雑に聞こえるので、
4 分 / 8 分 / 8 分裏 / 16 分の刻みを丸ごと 1 つ選んでから飾りを足す形にしています。

## 音づくりのメモ

- キック: サイン波のピッチを 141Hz → 46Hz へ一気に落とし、頭にノイズのクリックを重ねる
- スネア: 186Hz / 331Hz のサイン波 + ハイパスしたノイズ
- ハイハット: 6 本の矩形波を非整数倍で重ねてハイパス（減衰時間だけ変えてクローズド／オープン）
- クラップ: 10ms 間隔のノイズバースト 3 連発 + 残響
- コード: 整数倍の倍音を薄く重ねたドローバーオルガン風。ルートが F# 以上のコードは 1 オクターブ下げて、
  進行しても音の高さが飛び跳ねないようにしています
- ベース: 低次倍音だけの丸い音。リードは奇数倍音だけの矩形波寄りの音
- 音の長さは「次に同じ行が鳴るまで」。コードは小節いっぱい、ベースとリードは最長 4 ステップで切ります
- 同時に鳴った音が歪まないよう、出力の直前でソフトリミッタを通しています
- クローズドハットはオープンハットを止めます（実機と同じ挙動）
